# 脚本开发笔记 — 文档形成指导

> 本文档规定 `docs/脚本开发笔记/` 下所有文档的形成方式、目录结构、内容要求和编写流程。

---

## 一、目录结构

```
docs/脚本开发笔记/
├── 文档形成指导.md          ← 本文档
├── 通用/
│   ├── 开发规范.md
│   └── 开发注意事项.md
├── TT.Git.SplitCommit/     ← 每个脚本一个子目录，以脚本名（不含 .ps1）命名
│   ├── 脚本逻辑.md
│   ├── 使用注意事项.md
│   └── 问题与处理方法.md
└── TT.Git.CodeStat/
    ├── 脚本逻辑.md
    ├── 使用注意事项.md
    └── 问题与处理方法.md
```

新增脚本文档时，在 `脚本开发笔记/` 下创建同名子目录，放入三份文档。

---

## 二、文档拆分原则

**每个文档只聚焦一个主题，不把多主题塞在一个文件里。**

| 文档 | 职责 | 读者 |
|------|------|------|
| 脚本逻辑.md | 代码结构、核心流程、关键设计 | 需要理解/修改代码的开发者 |
| 使用注意事项.md | 用法、参数、边界行为、注意点 | 使用脚本的人 |
| 问题与处理方法.md | 开发中遇到的坑、根因、修复方案 | 未来遇到同类问题的开发者 |

通用文档独立于具体脚本：

| 文档 | 职责 |
|------|------|
| 开发规范.md | 项目级编码规范、结构约定、输出规范等 |
| 开发注意事项.md | 跨脚本通用的陷阱和应对方法（主要是 PS 5.1 / 编码 / Git 相关） |

---

## 三、内容来源

文档内容必须来自**实际开发过程**，而非凭空编写：

1. **脚本源码**：通读脚本，提取函数结构、核心流程、关键设计
2. **开发对话历史**：从 Bug 修复、用户反馈、设计演进中提取问题与处理方法
3. **用户偏好**：从长期记忆（MEMORY.md / USER.md）中提取编码习惯和输出偏好

不得编造未实际遇到的问题或未验证的方案。

---

## 四、编写流程

```
1. 读取脚本源码 → 理解逻辑
2. 读取已有文档 → 对齐格式风格
3. 读取开发历史 → 提取问题和处理方法
4. 按三个主题分别编写
5. 自检：工作区路径、内容准确性
```

### 关键步骤说明

#### 步骤 1：通读脚本源码

- 理解整体流程和核心函数
- 识别关键设计决策（如"为什么用累积模式而非增量模式"）
- 提取函数调用关系和数据流

#### 步骤 2：对齐格式风格

- 读取同目录下已有的文档，保持标题层级、代码块、表格等格式一致
- 新脚本组的第一份文档参考已有脚本组的格式

#### 步骤 3：提取问题和处理方法

- 从开发对话历史中提取实际遇到的 Bug 和陷阱
- 按"现象 → 根因 → 处理方法"三段式记录
- 附上代码示例（❌ 错误写法 / ✅ 正确写法）
- 通用问题（如 PS 5.1 陷阱）归入通用文档，脚本特有问题归入脚本文档

## 五、格式规范

### 文档头部

每份文档开头用引用块标注脚本路径和关键信息：

```markdown
# TT.Git.XXX.ps1 脚本逻辑

> 脚本路径：`bin/TT.Git.XXX.ps1`
> 用户命令：`Get-GitXxx` / `Set-GitXxx`
> 功能：一句话说明
```

通用文档无需脚本路径，写适用范围：

```markdown
# TT.ToolKit 开发规范

> 适用范围：`powershell-mykit` 项目的所有 PowerShell 脚本（`bin/TT.*.ps1`）
```

### 标题层级

- `#` — 文档标题（仅一个）
- `##` — 主要章节
- `###` — 子章节

### 代码块

- PowerShell 代码用 ````powershell` 标记
- 错误/正确对比用 `❌` / `✅` 前缀

### 表格

- 用于参数说明、方案对比、颜色约定等结构化信息
- 列对齐，表头加粗

### 分隔线

章节之间用 `---` 分隔。

## 六、质量检查

| 检查项 | 要求 |
|--------|------|
| 文件位置 | 必须在 `docs/脚本开发笔记/` 下的正确子目录 |
| 内容真实性 | 所有问题和处理方法来自实际开发，无编造 |
| 格式一致性 | 与同目录已有文档风格一致 |
| 代码准确性 | 代码示例必须与实际脚本代码一致 |
| 交叉引用 | 脚本特有问题不与通用文档重复（通用陷阱只归通用，脚本文档引用即可） |
