# TT.Git.SplitCommit.ps1 使用注意事项

> 脚本路径：`bin/TT.Git.SplitCommit.ps1`
> 用户命令：`Split-GitStagedCommit`

---

## 基本用法

```powershell
# 加载脚本
. G:\path\TT.Git.SplitCommit.ps1

# 实际提交
Split-GitStagedCommit -MaxBytes 10240 -Message "feature: 新增模块"

# 模拟分批（不执行 git 操作）
Split-GitStagedCommit -MaxBytes 5120 -Message "feat" -DryRun

# 查看帮助
Split-GitStagedCommit -Help
```

---

## 注意事项

1. **操作对象仅为暂存区**：必须先 `git add`，脚本读取暂存区内容
2. **不执行 `git push`**：仅本地提交，需手动推送
3. **未暂存改动全程保留**：`git reset` + `git commit` 只操作暂存区，不修改工作区
4. **子目录运行**：脚本自动切换到仓库根目录，确保获取完整暂存区文件列表
5. **中文路径仓库**：已适配代码页 936，可正常使用
6. **DryRun 先行**：建议先 DryRun 查看分批计划，确认无误后再正式执行
7. **单行文件超限**：行是最小切分粒度，单行超限只能整文件提交（与二进制文件一致）
8. **备份文件**：执行前保存 diff 到 `.git/TT.ToolKit/split-tmp/`，异常退出时保留；正常完成后自动清理
9. **失败恢复**：提交失败时自动用 `stagedInfo` 恢复未提交文件到暂存区
