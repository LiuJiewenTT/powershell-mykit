# TT.Git.CodeStat.ps1 脚本逻辑

> 脚本路径：`bin/TT.Git.CodeStat.ps1`
> 用户命令：`Get-GitCodeStat` / `Get-GitCodeLineStat` / `Get-GitCodeCharStat` / `Get-GitCodeByteStat` / `Get-GitCodeNewByteStat`
> 功能：统计 Git 变更代码的行数、字符数和 UTF-8 字节数，四种方案独立可用

---

## 整体流程

```
参数解析 → 参数互斥校验 → 仓库检查 → 获取 git diff 输出 → 逐行计算行数/字符数/字节数 → 输出/返回
```

---

## 四种统计方案

| 方案 | 命令 | 统计内容 |
|------|------|----------|
| 方案1 | `Get-GitCodeLineStat` | 行数（新增/删除/合计） |
| 方案2 | `Get-GitCodeCharStat` | 字符数（新增/删除/合计） |
| 方案3 | `Get-GitCodeByteStat` | UTF-8 字节数（新增/删除/合计） |
| 方案4 | `Get-GitCodeNewByteStat` | 仅新增代码 UTF-8 字节数 |
| 综合 | `Get-GitCodeStat` | 同时输出四种方案结果 |

---

## 核心函数

### `__GitCodeStat_Compute`

从 git diff 输出行计算行数、字符数和字节数的核心函数。

1. 过滤有效代码行：以 `+`/`-` 开头，排除 `+++`/`---` 文件标记行
2. 逐行处理：`Substring(1)` 去掉行首 `+`/`-` 符号
3. `-NoWhitespace` 时用正则 `\s` 移除所有空白字符，全空白行不计入行数（`continue`）
4. 按 `+`/`-` 分别累加行数、字符数、字节数计数器
5. 用 `[System.Text.Encoding]::UTF8.GetByteCount()` 计算 UTF-8 字节数

返回 `PSCustomObject`，包含 `Add_Lines`、`Del_Lines`、`Total_Lines`、`Add_Char`、`Del_Char`、`Total_Char`、`Add_Bytes`、`Del_Bytes`、`Total_Bytes` 九个字段。

### `__GitCodeStat_GetDiff`

根据参数选择 git diff 模式：

| 参数 | diff 命令 |
|------|-----------|
| `-Staged` | `git diff --cached` |
| `-Commit1 xxx -Commit2 yyy` | `git diff xxx yyy` |
| `-Commit1 xxx` | `git diff xxx HEAD` |
| 无参数 | `git diff HEAD^ HEAD`（首次提交用 `--root`） |

首次提交兼容：先 `git rev-parse --verify HEAD^` 检测，失败则切换 `--root` 模式。

### `__GitCodeStat_ValidateParams`

参数互斥校验：`-Staged` 与 `-Commit1`/`-Commit2` 不能同时使用。

### `__GitCodeStat_WriteFull`

打印综合统计（行数+字符+字节全量），标签间距硬编码对齐，数字右对齐带千分位（`{0,12:N0}`）。

---

## 综合入口 `Get-GitCodeStat` 的双模式

- **无参数**：同时统计暂存区 + 最新提交 HEAD，分别打印两区块
- **有参数**：单模式统计，打印一区块

`-PassThru` 返回值结构：
- 无参数：`@{ Staged = $stat; Head = $stat }`
- 有参数：单个 `$stat` 对象
